# Changelog

## 0.1.0 (unreleased)

- `@alter-ai/gmail-mcp`: `search_emails`, `read_email`, `create_draft`, `send_email` (held for approval under the recommended policy) and `check_approval`.
- Both servers can be hosted as Cloudflare Workers (`src/worker.ts`, `src/hosted.ts`, `wrangler.jsonc`): stateless Streamable HTTP behind an OAuth server built on `@cloudflare/workers-oauth-provider`. Hosted servers are multi-user: each person signs in through the Alter app's identity provider, is checked against `ALLOWED_USERS` (ids, emails, `@domain` or `*`), and their client's token is bound to their own connection delegated to the agent, found with their identity-provider token; first-time users connect their account from the sign-in page.
- Hosted servers bind each sign-in to the browser that started it. The Worker starts Alter's sign-in in redirect mode, Alter returns the browser to `/authorize/return` with a one-time code, and the Worker redeems it only for the browser holding the per-sign-in cookie set with the sign-in page; the poll no longer asks Alter for the result. Before this, a person who completed a sign-in link someone sent them gave the sender access as them. Operators must register `https://<worker address>/authorize/return` as a sign-in return URL on the Alter app, and the Worker needs an `@alter-ai/alter-sdk` release with redirect sign-in.
- `slack-approvals`: a Cloudflare Worker that turns Alter's `approval.requested` webhooks into Slack messages showing what will be sent, and decides from the Approve and Deny buttons as the clicking approver.
- `@alter-ai/x-mcp`: `get_profile`, `search_posts`, `get_mentions`, `create_post` (with `reply_to`), `like_post`, `repost` (posts, likes and reposts held for approval under the recommended policy) and `check_approval`, on X's official API only.
- `@alter-ai/notion-mcp`: `search`, `read_page` (Markdown), `query_database`, `create_page`, `append_to_page`, `add_comment` and `check_approval`, on Notion API version 2026-03-11; deletes blocked under the recommended policy.
- The shared Alter client accepts `PATCH` and `PUT` requests and raw byte bodies.
- Images, video and files: `@alter-ai/gmail-mcp` `send_email` and `create_draft` take `attachments` (any type, 5 MB in total); `@alter-ai/x-mcp` `create_post` takes `media` (up to 4 images, a GIF or a video, through X's chunked upload); `@alter-ai/linkedin-mcp` `create_post` takes `images` (1 to 20, with alt text) or `video` (MP4). Files come from a public https URL or, for a server running locally, an absolute file path (shared `src/media.ts`); the agent's reason names each file for the approver. The recommended X and LinkedIn policies hold posts and name the like, repost and reaction operations, so uploads are not each held for approval. X needs the `media.write` scope.
- `@alter-ai/gmail-mcp` adds the Gmail signature of the account's primary address to every send and draft, as text and HTML (`include_signature: false` leaves it out).
- `@alter-ai/gmail-mcp` `send_email` and `create_draft` take `from`: the primary address or a verified Gmail alias, with its display name and its own signature; other addresses are refused with the list of ones that work.
- `@alter-ai/gmail-mcp`: the HTML version of a message sets its font (Arial, 14px, as Gmail's editor sends), so clients do not fall back to their own (Outlook uses Times New Roman), and lines starting with `- `, `* ` or `•` become a list with space between the items. The signature now sits directly under the last line, with no blank line or `-- ` separator, as Gmail places it.
- `@alter-ai/notion-mcp`: `update_page` (title and properties from plain values, silent), `edit_page` (replace content, or find and replace; keeps child pages unless allowed), `create_database` and `add_database_columns` (typed columns), `move_page`, `trash_page` and `restore_page` (pages and databases); `create_page` takes `properties` for database rows. The recommended policy now holds deletes and moves for approval instead of blocking deletes, and the README no longer says appended Markdown escapes a hold on sends (Alter classifies it as `send`).
- `slack-approvals` lists email attachments and shows the images and video on LinkedIn posts and the media on X posts.
- `@alter-ai/linkedin-mcp`: `get_profile`, `create_post`, `comment_on_post`, `react_to_post` (held for approval under the recommended policy) and `check_approval`, on LinkedIn's official API only. `create_post` takes an optional `link` that LinkedIn shows as an article card.
